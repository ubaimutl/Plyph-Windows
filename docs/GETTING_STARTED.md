# Getting started

Plyph adds a floating toolbar to selected text in supported Windows apps. You need an x64 PC running Windows 10 or 11 and a model provider for the actions you want to use.

## Install and start Plyph

Download a package from [GitHub Releases](https://github.com/ubaimutl/Plyph-Windows/releases).

- **Installer** — Run `Plyph-Setup.exe` and open Plyph from the Start menu.
- **Portable** — Extract `Plyph-Portable-win-x64.zip` and run `Plyph-Portable.exe`. Keep the `app` folder next to the launcher.

Open Plyph’s system tray menu and choose **Settings → AI Providers**. Select a default provider and model. You can [connect ChatGPT through your browser](chatgpt-account.md), add a cloud API connection, or use a local model server such as Ollama or LM Studio.

## Run your first action

1. Open Notepad and select a sentence. Click the Plyph button if the toolbar is collapsed.
2. Choose **Correct** to fix grammar and spelling, or **Ask** to enter a question or request.
3. Review the result. Choose **Copy** or **Replace** when available.

If the toolbar doesn’t appear, try **Open Plyph Actions** from the tray menu or see [compatibility and limitations](LIMITATIONS.md). Use **Exit Plyph** in the tray menu to stop the app.
