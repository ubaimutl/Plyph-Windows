# Create reusable actions in Plyph for Windows

Use custom actions for edits you repeat, such as turning notes into bullets or drafting a reply.

1. Open **Settings → Actions & Prompts**.
2. Expand **Action library** and choose **Use template**, or click **+ New custom action**.
3. Name the action and choose an **Input mode**. Enter your instructions under **Prompt / Instructions**. Instructions are optional in **Run as prompt** mode.
4. Save the action. Open it from **More actions**, or pin it under **Settings → Toolbar → Pinned actions**.

## Choose an input mode

- **Transform text** applies your saved instructions to the selection. For example, write “Turn this into three bullets” as the instruction, then select the notes you want to edit.
- **Run as prompt** sends the selection as the request. For example, select “Draft a short reminder for Friday’s meeting.” Any saved instructions give the model additional guidance.
