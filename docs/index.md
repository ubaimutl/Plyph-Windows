# Plyph for Windows guides

Plyph is an open-source desktop text assistant for Windows 10 and 11. Select text in an app to correct, rewrite, summarize, or ask about it. You can review the result before copying it or replacing the selection.

- [Use your ChatGPT account without an API key](chatgpt-account.md)
- [Use and customize the floating toolbar](floating-toolbar.md)
- [Create reusable custom actions](custom-actions.md)

Get the installer or portable ZIP from [GitHub Releases](https://github.com/ubaimutl/Plyph-Windows/releases).
