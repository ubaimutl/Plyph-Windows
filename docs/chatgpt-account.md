# Use ChatGPT in Plyph for Windows without an API key

Connect your existing ChatGPT account to correct, rewrite, or ask about text from the floating toolbar. The **ChatGPT Account** provider uses browser sign-in without an OpenAI API key or separate Plyph account.

## Connect your account

1. Open Plyph from the Windows system tray and choose **Settings → AI Providers**.
2. Set **Default AI provider** to **ChatGPT Account**.
3. Click **Continue with ChatGPT**. Complete sign-in and approve plan usage if prompted.
4. Return to Plyph, choose a model, and try **Ask** or **Correct** on sample text.

Use **Add account** to connect another account, **Sign out** to disconnect the selected account, or **Manage usage** to open your ChatGPT usage settings. Plyph stores sign-in credentials in Windows Credential Manager in installed mode and in an encrypted local file in portable mode.

## ChatGPT usage and OpenAI API billing

Model availability and usage depend on your account and the access you grant. If plan access was denied or your connection expired, try **Continue with ChatGPT** again. [OpenAI’s guide to ChatGPT plan usage in other apps](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites)

If you prefer to use an OpenAI API key, add an OpenAI connection under **Saved OpenAI-Compatible Providers**. That connection uses separate API billing. [OpenAI’s billing guide](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)
